# ADR-039. Отчёт за период в Telegram Mini App

`GET /api/report?groups=2` использует ту же проверку входа Telegram и права
доступа, что и API дневника. Сервер принимает 2, 4 или 8 групп и вычисляет даты
по правилам `/report`. Ответ содержит доступные периоды, сводку и динамику по
включённым метрикам. Переключение метрики выполняется внутри Mini App.

Сводка и динамика рассчитываются в одном проходе по дневным данным. Цели
берутся из дневных снимков. Если снимка нет, применяется существующее правило
`/report` и снимок создаётся. При одновременном создании используется уже
сохранённый снимок. Группы и итоги отчёта вычисляются при запросе.

Для каждой группы среднее значение и средняя цель считаются по одним и тем же
дням с записями. Полоса допуска строится вокруг средней цели, а диапазон дневных
целей виден в деталях группы, если цели различались. Для счётчика выполнения
цели каждый пригодный день сравнивается со своей дневной целью.
