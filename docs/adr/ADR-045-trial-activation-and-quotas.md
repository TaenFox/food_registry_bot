# ADR-045: Пробный доступ к проектному ИИ

## Решение

- Первый `/start` нового Telegram ID создаёт профиль и допуск в одной транзакции. Базовая категория `external`, а поле `user_access.temporary_internal_until` открывает проектный ИИ на семь суток. Наличие строки доступа исключает повторную автоматическую выдачу. Существующие допуски, включая запреты, сохраняются при обновлении.
- Ручная выдача временного `internal` действует по прежним правилам. Истечение срока оставляет доступ к дневнику и возвращает постоянную категорию. Изменение срока администратором само по себе не сбрасывает дневной лимит.
- Для временного доступа к проектному ключу считаются семь запросов на ИИ-разбор записи и двадцать обращений к ИИ в диалоге за пищевой день. Лимиты независимы. Постоянный `internal`, администраторы и персональные ключи используют прежнюю политику.
- При исчерпании лимита запрос отклоняется до платного вызова. Попытка списывается при начале ИИ-обработки, включая результат с ошибкой. Успешный повтор идентичной отправки Mini App возвращает сохранённый результат. Быстрый ввод воды, импорт и повтор из истории в лимит не входят.
- Счётчики чата и Mini App общие для процесса и синхронизированы между потоками. Перезапуск обнуляет счётчики по согласованному правилу. Срок действия триала хранится в PostgreSQL. Для нескольких процессов потребуется общее хранилище.
- Приложение вычисляет ближайшую границу пищевого дня по текущим настройкам при первом запросе периода. Настройки могут меняться без сброса уже начатого периода.
- Фоновая проверка при запуске и затем раз в минуту отправляет первому ID из `ADMIN_USER_IDS` уведомление о завершившемся автоматическом или ручном триале. После подтверждения отправки очищается только тот срок, о котором отправили уведомление. До успешной отправки истёкший срок сохраняется для повтора. Допуск и постоянная категория остаются в `user_access`, повторный `/start` не выдаёт новый триал. После очистки бот использует обычное сообщение о недоступности ИИ, поскольку отдельная история триала не хранится.
