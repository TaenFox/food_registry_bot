# ADR-001: PostgreSQL as Source of Truth

## Context

Проект представляет собой Telegram-бот для ведения дневника питания, воды и тренировок.

Изначальная логика аналогичного решения была связана с Google Sheets, но для этого проекта требуется собственная модель хранения данных, поддержка нескольких пользователей и возможность постепенно развивать схему без привязки к табличному интерфейсу.

Также проект предполагается запускать через Docker и развивать инкрементально, с понятным подходом к миграциям и обслуживанию данных.

## Decision

- Основным и единственным источником истины для пользовательских данных выбирается PostgreSQL.
- Google Sheets не используются ни как основное хранилище, ни как обязательный интеграционный слой.
- Приложение проектируется под запуск в Docker-окружении.
- Изменения схемы базы данных вносятся через инкрементальные миграции.
- Документация и архитектура должны исходить из продуктовой модели данных, а не из структуры внешней таблицы.

## Consequences

- Проект получает устойчивую и расширяемую модель хранения данных без ограничений Google Sheets.
- Появляется возможность нормально поддерживать многопользовательский режим и связанные сущности.
- История, дневные агрегаты, настройки пользователя и расширяемые метрики могут проектироваться как нормальные доменные сущности.
- Появляется обязанность сопровождать схему БД и миграции как часть кодовой базы.
- При необходимости выгрузка в CSV или другие внешние форматы может быть реализована как производная функция, а не как часть источника истины.
