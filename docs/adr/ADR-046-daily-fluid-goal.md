# ADR-046. Цель по общему объёму напитков

«Выпито» включает обычную воду и позиции с признаком напитка и известным
объёмом в миллилитрах. Обычная вода отдельно видна под шкалами дневника.
Пищевые метрики напитков считаются по прежним правилам.

Для новой цели используется сохранённое в профиле количество миллилитров.
Новые снимки цели помечаются как применимые к общему объёму напитков.
Миграция помечает существующие снимки как цели по обычной воде и сохраняет
их значения. Дневник и отчёт показывают общий объём и на исторических
датах. Процент, достижения цели и пороги для «Выпито» вычисляются только
по снимкам с целью по общему объёму. В чате сохранённая цель отдельного
дня по-прежнему сравнивается с тем видом объёма, для которого она была задана.

Ключ `water` в API и команда `/goal water` сохраняются. Показатель в
пользовательском интерфейсе называется «Выпито».
