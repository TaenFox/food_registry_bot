# ADR-042. Импорт и экспорт CSV в Mini App

`GET /api/files` возвращает общий с `/files` список файлов пользователя.
`POST /api/files` принимает JSON с действием `export`, `import`, `download`
или `delete`. Действия над существующим файлом принимают его `file_id`.
Загрузка CSV использует `POST /api/files?name=<имя.csv>` с телом
`application/octet-stream` до 1 МБ. Успешное скачивание возвращает CSV,
остальные ответы возвращают JSON. Маршрут проверяет Telegram initData,
доступ и принадлежность файла пользователю.

Оба интерфейса используют `DataExchangeService`, существующее хранилище,
статусы и форматы CSV. Загрузка и запуск импорта выполняются отдельно.
Изменяющие операции обоих интерфейсов сериализуются на строке пользователя
в PostgreSQL. Повторное создание экспорта с тем же содержимым использует
существующий файл.

В развёртывании homelab Caddy напрямую направляет точный путь `/api/files`
в API-контейнер бота. Для выпуска требуется применить обновлённый Caddyfile
из homelab по инструкции этого репозитория.

В отдельном Compose этого репозитория `/api/files` проксирует Nginx. Метка
`APP_VERSION` обновляет контейнер Mini App при развёртывании новой версии,
чтобы Nginx прочитал конфигурацию с новым маршрутом.
