# ADR-040. Настройки Telegram Mini App

## Решение

`GET /api/settings` и `POST /api/settings` используют проверку Telegram и
правила доступа дневника. В настройках Mini App и `/settings` бота
используются одни и те же текущие цели, настройки отображения, флаг записи
тренировок и предпочтения по диетам.

GET возвращает текущие значения, доступные варианты и шаги целей. Для
профиля без сохранённых настроек он возвращает значения по умолчанию.
POST принимает только изменённые поля. В `goals`, `metrics` и `diets` можно
передать изменения отдельных показателей. Прочие поля соответствуют одноимённым
настройкам отчётов, отображения и записи тренировок из GET. Сервер принимает
только поддерживаемые метрики, варианты и включённые в системе диеты.

Изменения применяются в одной транзакции. Повторная отправка тех же значений
устанавливает их снова. Mini App отправляет абсолютные значения целей.
Шаг кнопок составляет 100 ккал, 5 г для БЖУ и клетчатки и 100 мл для воды.
Существующие снимки дневных целей остаются источником значения цели для
соответствующего дня.

Часовой пояс редактируется в `users.timezone`. Сервер принимает имена зон
из доступной базы IANA. Пользовательский контекст общий с командой
`/context` и хранится с тем же шифрованием. Пустая строка очищает контекст.
При недоступном шифровании остальные настройки остаются доступны.
