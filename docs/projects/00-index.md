# Индекс проектных артефактов

Этот каталог хранит проектные документы, которые помогают вести крупную функциональность по этапам.

Здесь лежат не общие пользовательские функции и не ADR, а рабочие проектные артефакты:

- целевая модель функциональности;
- согласованные ограничения;
- поэтапный план;
- критерии завершения этапов;
- удобная точка входа для продолжения работы в новом чате Codex.
