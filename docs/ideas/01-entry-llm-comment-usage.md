# Использование `entries.llm_comment`

Статус:

- `idea`

Контекст:

- после Этапа 3 `post-entry nutrition comment` уже сохраняется в `entries.llm_comment`;
- сейчас этот комментарий показывается только в confirmation response сразу после записи;
- в остальных пользовательских сценариях сохранённый comment пока не используется.

Идея:

- позже использовать `entries.llm_comment` как уже сохранённый nutrition-aware комментарий к записи, не пересчитывая его заново без необходимости.

Потенциальные направления использования:

- показать comment в будущем сценарии просмотра деталей отдельной записи;
- использовать comment как дополнительный контекст для объяснения последней записи в coach follow-up;
- выборочно показывать comment в историях или списках записей, если для этого появится отдельный UX-сценарий.

Что пока не делаем:

- не показываем `llm_comment` в `/recent`;
- не используем `llm_comment` в routing;
- не включаем `llm_comment` в factual summary дня;
- не строим под это отдельную persistence-модель.

Почему идея отложена:

- пока нет отдельного пользовательского сценария, где показ сохранённого comment даёт понятную пользу без лишнего шума;
- хранить comment в БД уже полезно, даже если его повторное использование будет решено позже отдельным шагом.
